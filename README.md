# HišniHeroj – Home Assistant add-on

Družinska aplikacija za opravila, točke in nagrade (PWA).

## Namestitev

1. Home Assistant → **Nastavitve → Dodatki → Trgovina z dodatki → ⋮ → Repozitoriji**
2. Dodaj: `https://github.com/TadejBartol/hisniheroj-addon`
3. Namesti **HišniHeroj**, nastavi `base_url` in zaženi.
